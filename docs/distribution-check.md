# 分发验收与适用范围

2026-11-15 按“第一次收到源码的人”进行 Windows 验收：从 GitHub 下载源码及已发布的 1.1.0 独立扩展，在全新 Python 3.10.11 虚拟环境安装 requirements.txt。

## 已验证

- 依赖安装及 pip check；演示模式自动建库，八个业务页面正常打开。
- 正式模式独立建库；从实际设置页保存测试凭据，点击同步，经正常接口客户端导入两笔合成订单。
- 浏览器真正加载发布版 MV3 扩展；通过实际网站地址接口，两个订单各自打开货源及结算页，收货人、电话和完整地址匹配，没有提交采购。
- 从实际选品页面启动收图，扩展回传至正确图片池；图片下载的网络边界使用合成图片。
- 正式模式停止再启动，订单及设置保留。
- 统一启动器固定演示/正式数据目录、使用项目虚拟环境，默认关闭业务调度；端口占用时停止，不结束其他进程。

平台接口与孔夫子/小红书测试页面均使用隔离测试数据。以上证明安装和主要集成链路可工作，不等于已在新用户真实账号上验证平台权限、实时网页变化、采购或自动发货。

## 发给别人前

1. 分享公开仓库或源码发行包，不要打包自己正在使用的整个目录。数据库、账号凭据、登录态及浏览器目录不可分享。
2. 接收者按 [Windows 安装说明](windows-install.md) 安装 Python 和依赖，先运行演示版，再启动正式版。
3. 接收者使用自己的闲管家接口授权、店铺及孔夫子账号，按 [独立扩展说明](browser-extension.md) 在自己的 Edge / Chrome 加载扩展。
4. 在自己的真实账号中先手动同步、核对订单与收货信息，再验证采购绑定及物流规则，最后决定是否开启自动任务。采购提交和付款始终由人确认。

源码包不是安装即用的 EXE。它提供订单、选品、模板、报表、采购辅助等同一类能力，不包含原作者的账号、订单或生产配置，也不保证不同账号、平台版本及部署环境的结果完全一致。服务器版本另见 [部署说明](server-deploy.md)，本轮未进行新的 Linux 服务器部署验收。
