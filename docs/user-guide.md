# 日常使用说明

先完成 [Windows 安装](windows-install.md)；本说明同时解释本地与服务器运行方式的差别。真实平台操作需要自己的账号权限。

## 第一次使用的顺序

1. 演示模式只浏览页面，确认环境能运行。
2. 使用独立正式数据目录，保存闲管家凭据，同步自己的订单。
3. 在项目专用浏览器登录孔夫子。
4. 先逐笔人工核对订单和采购绑定；确认流程适用后，再决定是否开启后台自动任务。

不要同时在两台机器上运行同一套真实业务自动任务。本地版网站没有服务器版登录保护，只供本机访问。

## 订单：同步、采购与发货

进入“订单”，点击“同步订单”。可按状态、关键词筛选并翻页。先确认书名、闲鱼订单号、店铺、订单状态和收货信息；退款、关闭或信息不全的订单不应继续采购。

### Windows 本地采购

1. 在待采购订单点击“找货源 / 去货源”，到孔夫子查看书籍版本、品相、价格和运费。这个普通浏览器链接本身不保证自动填写地址。
2. 确定书籍后回到该订单，点击“填单”。若尚未绑定货源，按提示粘贴本次选择的孔夫子商品链接。
3. 程序拉起专用浏览器，尝试进入购买页面并填写该订单收货信息。这里使用的是安装说明中登录过的项目浏览器。
4. 自己核对姓名、电话、完整地区、街道门牌、书籍版本、总价和留言。程序不替你提交采购或付款；确认后由你操作。
5. 完成后正常关闭该采购窗口，再处理下一笔。若页面改版导致无法识别，不要把提示失败当作地址已填成功，应人工处理。

仓库中的 `scripts/kfz_address.user.js` 是保留的历史云端脚本，指向示例域名，且相应本地接口存在模式限制；仅替换域名不等于完成本地适配。目前不要把它当成本地安装步骤。

### 服务器采购

服务器部署配置完成后，从订单点击货源入口，会先同步并回读核对本单地址，再导航普通孔夫子页面。你的普通浏览器必须登录与服务器一致的孔夫子账号。

这是共享账号的地址簿，不是为每个人建立独立结算会话。浏览器配送选择记忆、旧结算页和多人交叉采购都可能影响实际选中地址；逐笔采购、退出旧结算页，提交前人工核对。地址簿轮换不是所有新安装实例默认生效的行为，需按实际配置确认。

### 采购绑定与监控

系统尝试以收货信息及书名匹配采购订单。存在歧义时在“待确认采购”核对后选择绑定；也可以使用订单行的绑定表单填写真实孔夫子采购单号、采购总金额和链接。采购成本应包含运费。一笔销售订单可对应多个采购包裹，避免把同一采购单重复归属给不同销售订单。

绑定成功后进入采购监控。启用后台任务时，系统检查物流并重新核验订单状态、收货信息及运单，再尝试回填闲鱼发货。核验不通过时看订单警告并人工排查，不要为了放行而改成别人的电话或虚构地址。支付、退款、库存等最终状态仍以平台为准。

## 选品上架与店铺商品

在“选品上架”按书名或 ISBN 搜书，核对版本和商品信息，选择图片、标题与描述模板，设置价格并保存草稿。确认目标店铺后再执行发布；发布会向真实闲鱼平台提交数据。

“店铺商品”按店查看挂售记录及上下架状态。同一本书不同店铺的远端商品编号分别记录；修改价格、上下架前确认当前店铺和具体商品。

图池可收集、选取、排序及处理图片；平台网页变化、登录要求、网络或上传服务异常会影响抓图与发布。部分处理后的图片通过第三方临时图床生成公网地址，执行相应上传会把图片发送给外部服务。仅使用有权发布的图片，不要将带客户资料的截图作为商品素材上传。

## 热书榜、模板、报表与客户

- 热书榜：查看采集结果，按页面支持的方式刷新；抓取失败时不能把旧缓存当作实时榜单。
- 模板：维护标题和描述，发布前检查变量替换后的完整内容。
- 利润报表：基于本地订单、采购成本等记录计算，漏绑采购或缺运费会影响结果，不能当作财务结算凭证。
- 客户：用于查看历史与复购情况，数据来自自己的订单，不向仓库上传客户列表。
- 系统设置：管理闲管家凭据、店铺映射、孔夫子登录和服务器相关状态。

## 停止、备份、更新

Windows：在网站终端按 Ctrl+C；服务器需停止对应 Web/worker 服务。先让采购和登录窗口正常结束，不要强关正在提交的采购页面。

备份应在网站与后台任务停止后进行。完整复制自己的数据目录（例如 `data/live`）到私有备份位置；除数据库外，图片缓存和浏览器登录态也在其中。服务器另需备份受限配置目录中的会话密钥、登录哈希和孔夫子加密密钥，密钥与加密凭据须配套恢复。浏览器登录态属于敏感凭据，不能公开共享。

更新前先备份。ZIP 用户将新源码解压到新的文件夹，安装依赖后显式指向原数据目录的绝对路径；不要用别人的数据库覆盖自己的数据，也不要同时运行新旧实例。Git 用户先检查 `git status`，保留自己的修改，再决定如何合并远端更新。

## 使用范围与验收

完成安装后，应能打开八个页面；完成账号配置后，应先核对至少一笔真实订单，再验证自己的孔夫子登录和本地填单。只有实际看到收货信息一致才能认为本次填单成功。发货回填的结果要在闲鱼平台再次确认。

仓库离线测试不能替代你自己的平台权限、浏览器环境和真实业务验证。验证码由人处理；采购提交和付款始终由人决定。
