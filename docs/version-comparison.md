# 与最初源码、现用网站的区别

本次对照的“最初源码”是原本地仓库保存的 Git 基线 `ea860ee`（47个受版本控制文件）。它不是对第三方网站隐藏源码的比较，也不能代表你现在服务器的每一个文件。

| 方面 | 最初保存的本地基线 | 当前开源仓库 |
| --- | --- | --- |
| 安装交付 | 简短 README、手工配置较多 | Windows、日常使用、服务器部署和插件安装教程，演示/正式数据分目录 |
| 常用浏览器采购 | 依赖分散的脚本及项目专用浏览器 | 一个独立扩展，按订单读取最新地址、按真实导航来源关联结算页 |
| 收图和采购提示 | 多个独立辅助脚本 | 同一扩展提供小红书/孔夫子收图及手工提交后的待付款提示回传 |
| 标签页隔离 | 旧实现中存在“当前目标”等全局状态 | 地址、图池都绑定各自标签，不借用全局最后一单；回传订单提示带具体销售订单 ID |
| 运行方式 | 主要面向本机，数据库与程序同目录 | 可设置独立数据目录、关闭调度；提供 Web/worker 分离的服务器入口和服务模板 |
| 开源整理 | 自用目录需要自己识别运行数据 | 公开副本排除真实数据库、凭据、登录态和原 Git 历史，附许可证及第三方资源说明 |
| 验证 | 基线没有当前这套自动化回归目录 | 后台接口、DOM规则和真正加载 MV3 扩展的隔离浏览器测试 |

主要优势是更适合别人安装、维护和分发，并减少辅助工具混用。订单同步、采购绑定、物流回填、选品、模板、报表等业务核心仍来自原项目；不能仅凭仓库文件更多就声称全部业务更准确、真实交易零风险。

## 与你当前正在使用的网站

开源仓库没有部署到你的正式服务器，也没有修改你原来的本地项目。它不包含你的真实订单、账号凭据、孔夫子登录态或生产环境配置。

你的现用网站包含之前逐次部署的业务修复与特定账号配置；开源版把可分发的代码和安装方式独立整理了出来，新的独立扩展也是开源仓库的新能力。因此“业务目标相同”不代表“当前运行状态与页面行为完全一样”。

本次更新只统一仓库的浏览器辅助方式，不迁移真实业务、不启用本地任务、不修改线上采购或发货。真实 Edge 账号及实时平台页面仍需另外验收；测试中的模拟订单不等于真实交易验证。
