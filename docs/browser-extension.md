# 独立浏览器扩展（推荐）

无需安装 Tampermonkey。一个原生 Manifest V3 扩展包含本地订单取址、采购标签关联和孔夫子结算填址。兼容 Chromium 系浏览器，面向 Edge / Chrome 桌面版。

## 下载与安装

下载仓库 Release 中的 `xianshushu-address-helper-1.0.0.zip`，或在新版闲书书“系统设置”点击“下载 Edge / Chrome 扩展包”。也可直接从源码中使用 `browser-extension` 文件夹。

[直接下载 1.0.0 扩展包](https://github.com/wutuobang888/xianshushu/releases/download/address-helper-v1.0.0/xianshushu-address-helper-1.0.0.zip)

1. 解压 ZIP 到固定文件夹，确认里面能看到 manifest.json。
2. Edge 地址栏打开 `edge://extensions/`；Chrome 打开 `chrome://extensions/`。
3. 打开“开发人员模式”，点击“加载解压缩的扩展程序”。
4. 选择包含 manifest.json 的文件夹，不要选择 ZIP 文件或它的上一级文件夹。
5. 确认扩展列表出现“闲书书采购地址助手”1.0.0，开关已开启。
6. 关闭旧的油猴地址脚本，刷新闲书书订单页，确认绿色“闲书书扩展已启用”。

目前没有扩展商店链接。正式发布到 Edge Add-ons / Chrome Web Store 后才可以使用商店一键安装；本包不绕过浏览器的官方安装机制。安装步骤参考 [Microsoft 官方本地加载教程](https://learn.microsoft.com/microsoft-edge/extensions-chromium/getting-started/extension-sideloading)。

## 本地版使用

先按 [Windows 安装说明](windows-install.md)启动网站并配置自己的闲管家账号，同步真实订单。在安装扩展的同一个 Edge / Chrome 用户配置中登录孔夫子。

本地默认支持 http://127.0.0.1:5000 和 http://localhost:5000 。点击扩展图标可打开本地订单页。

从某一订单点击“找货源 / 去货源”，扩展先通过本站会话和 CSRF 接口读取并核实该笔最新地址，再打开孔夫子货源标签页。进入购买页面后，选择完整匹配地址，或尝试新增、校验并回读；看到核对成功提示后，你再核对图书、收货人、电话、门牌和金额，自行决定提交与付款。

每个采购标签页单独关联订单，购买弹窗沿父标签继承关联，不使用全局最后一单，也不把地址写到 URL。请沿货源标签页进入结算；复制裸链接到全新标签页可能没有关联，扩展不会猜测地址。

地址有效期10分钟，过期回订单页重新打开。不要依赖旧结算页或手动切换过的收货地址。无法识别、地址簿满额、字段不一致时停止自动填写；扩展不覆盖或清理其他地址，也不自动提交采购、付款。

## 服务器版使用

点扩展图标，在“你的闲书书服务器网址”填写自己的 HTTPS 网站，点击“连接此网站”，在浏览器提示中授权该具体网站的访问权限，再刷新订单页。不要填写孔夫子网址或其他人的网站。

配置只保存在本机。扩展不会索取网站密码或读取 Cookie；通过你已登录的网站页面同源调用取址接口。服务器须已部署包含 `/orders/<id>/browser_target` 的兼容代码；如果页面未显示启用提示或请求被拒绝，应先核对服务器版本和登录状态。

在云端订单页，扩展优先处理对应订单的货源入口，使用浏览器自身填址流程；未安装扩展的用户仍按服务器原有流程操作。扩展安装不会自动修改或部署服务器代码。

## 权限和隐私

- `storage`：设置与10分钟订单上下文；地址只使用 storage.session 会话内存，不同步到其他设备。
- `scripting`：用户主动连接自己的服务器时，为该已授权站点注册内容脚本。
- `alarms`：定期清理过期上下文。
- `webNavigation`：仅监听孔夫子业务域名的新标签导航，确认真实发起标签，避免用“当前前台标签”误判订单；不记录其他网站浏览历史。
- 默认站点访问权限：本机 localhost / 127.0.0.1，以及 book、item、search、order 四个孔夫子域名。脚本本地业务仅在5000端口启用。
- 可选 HTTPS 权限：仅在用户连接服务器、同意该域名后生效；不会默认授权所有 HTTPS 网站。

不读取密码和浏览器 Cookie，不发送遥测，不把地址上传给开发者。详见 [扩展隐私说明](../browser-extension/PRIVACY.md)。

## 更新与排错

- ZIP 并不能双击安装：先解压，再加载包含 manifest.json 的文件夹。
- 看不到绿色提示：确认扩展开关、站点访问权限、网站已启动及默认端口，刷新订单页；服务器用户重新检查连接网址。
- 无法读取订单：确认网站代码已更新、已登录、闲管家授权正常、订单仍待发货，刷新页面获取新 CSRF。
- 没有自动填址：确认从本单货源入口进入，地址未过期，在扩展所支持的孔夫子结算页面；不要拿旧标签页代替本次采购。
- 同时安装旧油猴：禁用旧地址脚本，避免重复处理；本扩展无需油猴。
- 更新后：在扩展管理页重新加载，再刷新订单页和采购页。已有未完成采购先核对并正常结束。
- 仅安装扩展不能使用：它仍需要自己运行的闲书书网站、自己的平台权限及孔夫子账号。

## 开发与打包

在仓库根目录执行 `python scripts/package_extension.py 输出路径.zip`。固定文件白名单打包，不包含数据库、账号、日志或浏览器登录态。不要把自己的运行数据塞进 browser-extension 文件夹。

扩展包内没有远程可执行脚本。原 `extension/` 是项目浏览器内部使用的“下单上报”旧模块；对外安装应使用本次 `browser-extension/`，不要混淆。

测试：`node --test tests/native_extension.test.js`；安装开发测试依赖及 Playwright Chromium 后，运行 `python -m unittest discover -s tests -p test_native_extension_browser.py -v`，会在独立配置中加载真正的扩展包，模拟两笔采购，不读取用户浏览器或平台账号。

1.0.0 已通过后台策略、本地接口与固定安装包检查、填址引擎 DOM 回归，以及真正加载 MV3 扩展的离线浏览器测试。真实 Edge 用户配置、账号和当前孔夫子页面仍需首次人工核对，不把模拟订单测试当成真实采购验证。
