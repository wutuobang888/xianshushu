# 本地油猴地址助手安装与使用

旧版兼容文档。新安装推荐[独立浏览器扩展](browser-extension.md)，无需油猴。不要同时启用两种地址助手。

适用于已按 [Windows 安装说明](windows-install.md)启动闲书书的人。使用同一个 Chrome 或 Edge 浏览器访问本地闲书书和孔夫子，不需要为采购打开项目专用浏览器。

## 1. 安装扩展并允许脚本运行

打开 [Tampermonkey 官方网站](https://www.tampermonkey.net/)，选择自己的浏览器，从官方商店安装 Tampermonkey。

安装后进入浏览器扩展管理页，打开 Tampermonkey 的详情，按浏览器提供的选项开启“允许运行用户脚本 / Allow User Scripts”。旧版本可能需要开启开发者模式，具体按 [Tampermonkey 官方说明](https://www.tampermonkey.net/faq.php?locale=en&q=Q209)操作。扩展必须有权在本地闲书书和孔夫子页面运行。

## 2. 安装本地地址助手

1. 确认本地网站终端仍在运行。
2. 在自己准备采购的浏览器打开 http://127.0.0.1:5000/settings 。
3. 找到“本地油猴地址助手”，点击“安装 / 更新本地地址助手”。
4. Tampermonkey 显示脚本安装页，确认名称“闲鱼选品-孔夫子填地址”、版本 2.1.0，然后点击安装。
5. 返回 http://127.0.0.1:5000/orders 并刷新。页面出现绿色“地址助手已启用”才说明脚本正在运行。

默认也支持 http://localhost:5000 。同一轮操作保持同一个地址，不要中途从 localhost 切换到 127.0.0.1，否则需要重新刷新并读取本单信息。

如果看到的是脚本文本或下载文件，没有安装页：打开 Tampermonkey 管理面板 → 添加新脚本，把该页面**完整源码**粘贴到编辑器，替换编辑器自带模板并保存。然后确认脚本已启用，刷新订单页检查绿色提示。不要同时启用重复的旧脚本。

不要把浏览器地址改成其他端口或局域网 IP 后期待脚本继续生效；当前直接安装支持默认 5000 端口，接口仅允许本机地址。服务器自定义域名是另一套部署配置。

## 3. 配置自己的真实账号

先按安装说明使用 `data/live` 正式数据目录，保存自己的闲管家 AppKey/AppSecret，点击“同步订单”。演示假订单没有真实平台身份，无法取得最新地址，所以不能用它验证真实采购填址。

在**同一个浏览器、同一个浏览器用户配置**中登录孔夫子。油猴不会读取或复制项目专用浏览器的登录 Cookie。仅用油猴采购无需启动项目登录命令；要同时使用后台查单和物流监控，仍须单独登录项目专用浏览器。

## 4. 逐笔采购

1. 在本地订单页确认绿色提示存在，找到待采购订单，点击它的“找货源 / 去货源”。
2. 浏览器先开空白标签页，读取并核验本单最新收货信息，再导航孔夫子；读取失败会关闭空白页并提示原因。请允许本地网站打开新标签页。
3. 在该孔夫子标签页挑选书籍并点击购买，保持这条访问链路。不要复制裸商品链接到另一个全新标签页，也不要关闭带关联号的页面后期待脚本猜出订单。
4. 进入结算后，脚本查找姓名、电话和完整地址一致的条目并选中；没有完全一致的地址时，尝试使用孔夫子“新增收货地址”入口智能识别、校验、保存并回读。
5. 看到“本单收货地址已填写并核对”后，自己再次核对收货人、手机、门牌、图书版本和金额，再手动提交采购并付款。

默认备注为“无需发票，请勿放任何店铺信息”。孔夫子页面未提供可识别备注入口时可能无法填写，提交前自行检查。

脚本不会自动提交采购或付款，也不会删除旧地址或覆盖其他收货地址。地址簿已满、没有新增入口、地区识别错误或保存后回读不一致时停止自动填址，并尝试把本单完整地址复制到剪贴板，供你人工处理。脚本仍可能阻止未通过核对的提交；需要完全人工处理时，先禁用此脚本、关闭本次结算，从头核对后操作。

## 5. 时效、多标签页与隐私

- 地址上下文有效期 10 分钟，每笔分别存储；URL 只带随机关联号，不带姓名、电话或客户地址。
- 一笔成功填写后不自动重复执行。超过 10 分钟、刷新了旧结算或丢失上下文时，回本地订单页重新从该订单打开，不要使用“最后一单”猜地址。
- 不同订单标签页各有自己的关联号。仍建议逐笔操作，提交前核对，避免人工把书和订单混用。
- 地址缓存在 Tampermonkey 隔离存储中；页面保持打开时到期清理，下次从订单打开货源也会清理过期项。若浏览器已关闭，物理缓存可能保留至下次清理，但过期项不会被用于填址。
- 识别失败可能复制客户地址到剪贴板。不要把这些内容贴到公共聊天、Issue、截图或代码仓库。

## 6. 常见问题与更新

| 问题 | 处理 |
| --- | --- |
| 没有绿色启用提示 | 检查扩展、用户脚本权限、站点访问权限、脚本启用状态及当前 URL，刷新订单页 |
| 安装后无反应 | 确认版本 2.1.0，使用同一浏览器配置，禁用重复旧脚本 |
| 弹窗被拦截 | 允许本地网站打开新标签页，再从本笔订单重试 |
| 提示登录过期或接口 403 | 确认网站已重启为新代码，刷新订单页；不要手工重放旧 CSRF 值 |
| 提示无法核实最新地址 | 检查自己的闲管家授权、订单是否仍待发货及地址完整性；不回退使用旧客户地址 |
| 结算没有填址 | 确认从本地订单入口进入、上下文未过期，且扩展可以在 order.kongfz.com 运行 |
| 找不到新增入口或识别失败 | 孔夫子页面布局或地址信息可能不匹配，按提示人工处理；不保证跨改版始终成功 |
| 地址簿满 20 条 | 脚本不自动清空或删除，请自行管理地址簿后重新从订单进入 |

更新仓库源码并重启网站后，在设置页再次点击“安装 / 更新”，确认 Tampermonkey 中的新版本，然后刷新订单页。脚本安装和权限确认由使用者在自己的浏览器完成。

## 验证范围

隔离测试使用模拟平台接口、合成订单地址和真实浏览器 DOM，覆盖本地取址、CSRF、标签页关联、选择/新增/回读、识别错误、过期信息及不自动提交。测试通过不代表已在你的真实 Tampermonkey 配置和孔夫子账号完成采购验证。首次使用应逐项核对；遇到验证码自行完成。
