# 安装闲书书采购地址助手

这个文件夹本身就是独立的 Edge / Chrome 扩展，独立安装。

1. 将 ZIP 解压到固定文件夹，不要直接在 ZIP 内操作。
2. Edge 打开 edge://extensions ，Chrome 打开 chrome://extensions 。
3. 开启“开发人员模式”，点击“加载解压缩的扩展程序”。
4. 选择这个包含 manifest.json 的文件夹。
5. 停用旧版地址辅助工具，避免同时运行两套采购助手。
6. 启动自己的闲书书本地版，在同一浏览器打开 http://127.0.0.1:5000/orders 并刷新。
7. 确认页面显示“闲书书扩展已启用”，从对应订单的货源入口进入孔夫子。

首次使用请核对书籍、收货人、手机和完整地址。扩展不自动提交采购、不付款。地址簿满额或识别错误时停止，由你人工处理。

收图：从闲书书图池点击小红书或孔夫子找图，在笔记/卖家商品页点击浮动收图按钮。保留原图池标签页，图片回传到该书图池。采购中只有你手工点击提交后，扩展才回传关联销售订单的待付款提示；不操作平台提交或付款。

如果使用自己的 HTTPS 服务器，在扩展图标弹窗中填写网站网址，点击“连接此网站”，按浏览器提示授权该网站，刷新订单页。服务器必须运行兼容的闲书书代码，并已登录网站账号。

1.1.0 整合了地址、收图和待付款提示，请与当前仓库网站代码配套使用；更新扩展本身不会更新已有服务器。

扩展和闲书书网站是两个组成部分：安装扩展不会替你安装 Python、启动网站、提供平台账号或闲管家接口权限。浏览器在孔夫子的登录状态与服务器后台浏览器的登录状态也各自管理。

升级：用新包解压到新文件夹后，在扩展页移除旧版本并加载新文件夹，或覆盖原源码文件后点击扩展卡片“重新加载”。不要同时启用两个版本。

尚未发布扩展商店，当前使用浏览器官方的“加载解压缩的扩展”安装方式；ZIP 不是可以直接双击安装的商店包。
